# Alarm!NG
Alarm!NG (Pronounced alarming) is a light, fast &amp; simple python &amp; curses based TUI alarm clock implemented on systemd.timer (requires systemd). It is built on the simple principle of simplicity and minimalism. While still in its beta stage with a lot of possible bugs and missed chances at optimization, Alarm!NG aims to provide all the features required to move users who require alarms out of crontab caves.

Originally made for myself, I decided to Alarm!NG in case anyone else requires the same functionality as me.
It also comes with an original alarm track which can be replaced at any time with your own track from the TUI or using the config file.
